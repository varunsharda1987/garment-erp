**Before you start:** Quick-add is not its own page. It opens from inside a style, so you must be creating or editing a style first. The material you create is added to that style's trim list and linked to the style by its **Style Code**. For a new style, that code only exists once **1. Basic Info** is filled: select the brand and category (for the in-house brands Kasya and Nihsamah, the **Buyer Style Code** you type becomes the Style Code instead). Only Admin and Merchandiser roles see the create and edit buttons.

## Steps

1. Open **Styles** in the sidebar. Click **+ Create New Style**, or open an existing style and click **Edit**.
2. For buttons, zippers, threads, elastic, lace and all other trims, go to tab **3. Trims & Materials**. For labels and packaging, go to tab **4. Accessories**.
3. Click **Browse & Add Trims** (or **Browse & Add Accessories**). A browse window opens.
4. Search the browse window first — the item may already exist. Type at least 2 characters in **Search all trims (name, code, color)...** or use the type tabs. Only if it does not exist, click **Create New** at the top right of that window.
5. The **Add New Material** dialog opens. The tile for the tab you were on is pre-highlighted, but you can pick any type: use **Search material types...** or scroll the category sections (Fasteners & Closures, Threads & Tapes, Decorative, Functional — or Accessories) and click the tile for the type you need.
6. The dialog changes to **Add New (type)**. Leave **Name** empty and the system builds the name from the details you fill in. Type a name only if you want to override that.
7. Fill the fields shown for that type — they change per type. Typical ones are Size, Material, Width, Composition, Brand, Length, Holes, and a **Color** box at the bottom. None of these are compulsory, but the more you fill, the better the auto-generated name.
8. Click **Create & Add**. **Cancel** or **Back** returns you to the type list without saving.
9. The new item is created, added to the style, ticked in its own type's tab of the browse window (even if you started from a different tab), and a confirmation message shows its generated name.
10. Click **Done** to close the browse window. Finish the rest of the style tabs and save the style as usual — the trim link is stored with the style.

## Notes and traps

- The item **code** is always generated by the system. There is no code field to fill.
- **Thread is the exception to the empty-name rule.** A thread will not save without a **Name** — type one, otherwise you get an "Invalid request data" error.
- For **Lace**, tick **This is Greige (raw) lace that needs dyeing/processing** if the lace still has to be dyed. The Color and price fields then disappear and **Expected Shrinkage %** and **Greige Cost (per meter)** appear instead. **Expected Shrinkage %** must be 0 or more and below 100.
- Quick-add cannot link a finished lace to the greige it was dyed from. To record a lace dyed FROM a greige, use **Create Dyed Variant & Cost** in the cost sheet's lace sourcing window so it is linked to its greige source, or set **Source Greige Lace (Optional)** on the full lace form.
- In the **Lace** list of the browse window, each lace shows its photo (or a 🎀 placeholder if none was uploaded). Use the photo to confirm you are picking the right lace before ticking it.
- Number fields must be numbers only — do not type units such as "mm" or "inch" into them.
- Quick-add creates a master record, not stock. Receive the actual quantity through a GRN separately.
