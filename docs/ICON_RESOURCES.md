## Integration Guide

### Method 1: Using Tabler Icons (Installed)

```tsx
// Import specific icons
import { IconShirt, IconScissors, IconRuler } from '@tabler/icons-react';

// Use in component
function MyComponent() {
  return (
    <div>
      <IconShirt size={24} stroke={2} color="blue" />
      <IconScissors size={20} stroke={1.5} />
    </div>
  );
}
```

### Method 2: Download and Add to CustomIcons.tsx

1. **Download SVG** from UXWing, Reshot, or Flaticon
2. **Optimize** using SVGOMG
3. **Add to** `frontend/src/components/icons/CustomIcons.tsx`:

```tsx
export const NewIcon: FC<IconProps> = ({
  size = 24,
  color = 'currentColor',
  className = '',
  ...props
}) => (
  <svg
    xmlns="http://www.w3.org/2000/svg"
    width={size}
    height={size}
    viewBox="0 0 24 24"
    fill="none"
    stroke={color}
    strokeWidth="2"
    strokeLinecap="round"
    strokeLinejoin="round"
    className={className}
    {...props}
  >
    {/* Paste optimized SVG paths here */}
  </svg>
);
```

4. **Update** `icon-library.ts` to include new icon

### Method 3: Generate with AI

1. **Visit** https://www.svgai.org/ai-icon-generator
2. **Enter prompt**: "fabric roll icon outline style"
3. **Select style**: Outline or your preferred style
4. **Download** SVG
5. **Integrate** using Method 2 above

### Method 4: Use Iconify (All Libraries in One)

```bash
npm install @iconify/react
```

```tsx
import { Icon } from '@iconify/react';

<Icon icon="tabler:shirt" width="24" />
<Icon icon="lucide:scissors" width="24" />
<Icon icon="mdi:sewing-machine" width="24" />
```
