What this report is actually for Per-processor tolerance is only meaningful if you have evidence to set it with. Without this report you end up giving a reliable dyer and a cheap one the same 3%, which quietly subsidises the cheap one. Ratan at 5.7% against a 3.0% tolerance has cost ₹31,620 in debit notes over six months — and that is only the portion that was caught. Loss inside tolerance never appears anywhere: it is absorbed into finished goods cost by design.
