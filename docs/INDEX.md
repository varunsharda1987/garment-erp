## 🎯 Quick Reference Card

### Configuration
```bash
cd backend
node scripts/configure-company-state.js  # Interactive setup
node scripts/verify-setup.js             # Verify configuration
```

### Testing
```bash
# Test states
curl http://localhost:5000/api/locations/states

# Test GST validation
curl -X POST http://localhost:5000/api/gst/validate \
  -H "Content-Type: application/json" \
  -d '{"gstNumber":"27AAACT1234E1Z5","stateCode":"27"}'
```

### Integration
```tsx
import StateSelector from '@/components/StateSelector';
import CitySelector from '@/components/CitySelector';
import GSTNumberInput from '@/components/GSTNumberInput';
import TaxBreakdown from '@/components/TaxBreakdown';
```

### Help
```bash
node scripts/list-states.js      # View all states
node scripts/verify-setup.js     # Check configuration
```
